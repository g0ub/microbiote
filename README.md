# Microbiote — Nos colocataires invisibles

Site de vulgarisation scientifique sur le microbiote intestinal : https://g0ub.github.io/microbiote/

- `index.html` : la page (HTML/CSS/JS autonomes, bilingue FR/EN)
- `media/` : vidéo *Ma thèse en 180 secondes* 2023 (Sabrina Huwart, UCLouvain), sous-titres FR/EN, illustrations
- `archive/annonce/` : l'ancienne page d'annonce « Coming soon » (aussi disponible via le tag `annonce`)

Les résultats collectifs du test de transit sont stockés dans une base Supabase (clé publique « publishable » dans `index.html`, accès limité à l'ajout de réponses anonymes et à des statistiques agrégées).
